Prijava

Ovdje možete dodavati vijesti i fotografije bez znanja programiranja. Promjene se spremaju u vaš GitHub repozitorij, a stranica se osvježi za otprilike minutu.

Token je lozinka samo za ovaj repozitorij. Kako ga napraviti: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Odaberite samo ovaj repozitorij i dozvolu Contents: Read and write. Ne dijelite ga ni s kim.
